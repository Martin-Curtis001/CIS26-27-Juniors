HTML Containers

Container

Any element with an opening and closing tag that holds content.

<div>

Generic block container with no meaning of its own. This tag is useless without a class or id attribute.

<span>

Generic inline container with no meaning of its own. This tag is useless without a class or id attribute.

Block vs Inline

A block container (block element) starts on a new line and stretches across its parent container's full width. An Inline container (element) - stays in the flow of the line and takes only as much room as its content.

Symantic elements

<article> Element - this contains content that can stand alone outside of the context of the current web page.

<aside> element - this contains content that can relates to the current web page indirectly, and is not part of the main content. an example of an aside would be an advertising link on a website, which is often created in a section off the right-side of a page.

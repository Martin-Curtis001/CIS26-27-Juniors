HTML lists

There are 3 types of HTML lists

Unordered lists

Unordered lists are lists that have bullet points to the left of each item. These lists are contained in an <u> tag. Each item in the list is contained in an < li> tag.

  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus
  • Kelab

NOTE: Unordered lists are the base HTML structure used to create navigation.

Ordered lists

Ordered lists are used to create a squence of items or steps. These list items have a number, roman numerals or alpha character to the left of each item. Like <u> items, ordered list items are contained in <>

  1. step one: crack eggs
  2. step two: add milk
  3. step three: whisk eggs and milk
  4. step four: pour into a hot pan
  5. step five: stir until done
